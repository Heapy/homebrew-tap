# homebrew-tap

Homebrew tap for Heapy tools.

```bash
brew tap Heapy/tap
```

## Formulae

```bash
brew install keemun
```

Or without tapping first:

```bash
brew install Heapy/tap/keemun
```

## Casks

### Kinetica Terminal

Native macOS terminal for Apple Silicon with Metal rendering, tabs, search and scrollback.

```bash
brew install --cask Heapy/tap/kinetica-terminal
```

Requires an Apple Silicon Mac and macOS Monterey or later. The current `0.1.0`
build is a preview, ad-hoc signed and not notarized by Apple. See the
[release notes](https://github.com/Heapy/kinetica-terminal/releases/tag/v0.1.0)
for known test failures and first-launch instructions. Older macOS versions have
not been tested; the release was tested on macOS 26.6.2.
